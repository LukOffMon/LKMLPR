# HighlyArtMon

Estudio de pixel art local conectado a Claude. Código y documentación: [`app/README.md`](app/README.md).

- `app/` — la app (paquete Python `highlyartmon`, sin dependencias) + tests.
- `install.ps1`, `install.sh` — instaladores de una línea.
- `site/` — sitio público, publicado en https://lukoffmon.github.io/LKMLPR/highlyartmon/ (el editor en modo navegador queda en `/highlyartmon/app/`).
